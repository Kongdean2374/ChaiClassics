開發分支：`develop/0.3.0`；已驗收基準：`e670922`（0.2.2）。本版補齊目錄中其餘 17 款遊戲，合計 25 款。未驗證的內容不標成完成，不將開發中分支自動上傳 TestFlight。

## 範圍

- 邏輯與拼圖：數織、數和、華容道。
- 棋類：五子棋、黑白棋、象棋、暗棋、西洋棋、將棋；離線 AI／同機雙人。
- 接龍：經典接龍、蜘蛛接龍、新接龍、金字塔接龍、三峰接龍。

全部使用既有對局結算／暫停、單遊戲設定、搜尋及篩選紀錄、匯入匯出、雙語、主題與美術材料。每款規則獨立，既有八款的存檔 namespace／payload、Bundle ID、150 題數獨與簽署資產不變。

## 共用確認與續玩手勢修正

0.2.2 實機回報：滑動續玩列有時同時觸發續玩；左滑刪除先讓列消失，確認框的兩個按鈕可能無反應。0.3.0 改為一般紅色 swipe action，禁止原生 destructive 的預先移除；確認視窗在自身生命週期內持有一次性回應狀態，不捕捉父列尚未建立的 token。背景在通知開啟時停止接受輸入。以原生 UIKit 觸控觀察器隔離拖曳、取消、反向滑動與多指觸控，不攔截系統捲動或左滑功能。

所有遊戲遵循同一規則：滑動不續玩、不刪除；點選刪除僅顯示確認；取消後進度與歷史不變，重開 App 仍能繼續；只有確認才刪除該遊戲的目前進度。新局覆蓋、清除與匯入取代也只在確認後提交。保留重複點擊與過期回應的防護。新增觸控狀態測試，原八款 UI 對局路徑增加左右滑誤觸檢查，以及取消刪除後重啟 App 的保存驗證。實際 iOS UI 結果待補。

## 第一階段：規則與共用介面

已實作 17 款規則引擎、雙語遊戲畫面、25 款目錄與新增插畫；新遊戲接入既有的對局／設定／存檔及備份架構。第一輪新增的 36 項核心測試通過，包括唯一解、棋類特殊規則、八方向翻子、暗棋資訊隔離、五款接龍、街機碰撞、資料隔離及舊備份相容。全套 214 項第一次回歸中的競態測試仍寫死八款遊戲的工作數，已修正為每款八次並另行重跑；此處不代表最終候選或 iOS 畫面驗證已通過。

## 第二階段：操作回歸與發布門檻

補上 17 份由真實 Core 驗證可合法結算的固定 UI 種子；僅放入測試 bundle，不放入正式 App。每款 UI 路徑涵蓋原生左右滑、取消與確認刪除、程序重開、暫停／退出／繼續、實際完成或失敗、結果回看、歷史、取消覆蓋及建立新局。六款新棋類另外操作新棋局並等待真實離線 AI 回應。

貪吃蛇與落塊開始／恢復時先倒數三秒；將棋持駒列可水平捲動；接龍歷史依實際抽牌／花色模式記錄難度。暗棋另外修正共用棋子 ID 與暗棋等級不同的車馬比較，困難 AI 評估公開棋子的回吃風險，仍不讀暗面身分。

221 項完整 Swift 測試已在 Linux 通過；其後新增的暗棋規則及 AI 測試另外驗證。249 項 Python 檢查、Ruby workflow/YAML、原 150 題唯一解與不可變題庫相容檢查通過。這些結果不代表 iOS UI／TF 已通過。

上一輪 Actions 的 Swift 規則與 App build 通過，但 UI bundle 因測試輔助程式變數作用域錯誤未編譯；已修正。工具測試的舊版目錄與來源雜湊契約也已逐項更新。下一輪實際 iPhone／iPad 結果待補，不引用失敗 Run 作為發布證據。

0.3.x 要求完整候選證據，明確拒絕舊 0.2.x 手動 QA 模式。保留全部既有 UI 斷言，新增到 67 個案例、26 條必要對局／歷史路徑；可分組與依相依來源重跑。簽署與上傳 job、憑證及 Secrets 不變。
