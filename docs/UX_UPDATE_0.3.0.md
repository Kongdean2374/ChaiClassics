# 0.3.0 操作改善批次

維持 0.3.0、新增 TestFlight Build，不變更 Bundle ID、舊題目或存檔格式。

- 五款接龍：長按拖曳可搬單張／合法連續牌組；金字塔可拖曳配對，三峰可拖到翻開牌。滑過不搬牌，合法落點有框線；無效、重複、舊盤面及暫停後的拖曳不改資料。原點選操作、復原及縮放保留。
- 貪吃蛇：四方向搖桿與方向按鈕，依主要軸判斷方向，保持禁止倒退與轉彎佇列規則。搖桿即時跟隨手指，不加慣性；棋盤格線、蛇頭方向辨識改善。
- 落塊：實際保留／下一塊形狀預覽、等級、左右拖移、點棋盤旋轉、向下快滑直接落下。左右／下鍵支援長按連續操作；暫停、系統手勢取消及離開會清除按住狀態，舊手勢不能落下下一塊。
- 數織：提示區隨實際行列提示長度擴展，避免大棋盤文字被裁切。
- 街機暫存畫面不得在清除／匯入／新局後回寫舊局；存檔失敗時回復已保存狀態並暫停。落塊私有計數及華容道極端輸入／存檔座標檢查補強。

已在 Linux 執行 49 項 V030 局部核心測試，包含其餘新增棋類 AI／合法走法、數織／數和、接龍及街機規則；沒有執行全遊戲 Simulator UI。後續修正僅重跑受影響案例。Swift 語法檢查不能代替真正 iOS SDK 編譯，正式 Archive 由這批唯一一次 TestFlight 流程驗證。

真機待驗證：五種接龍拖曳／取消／縮放邊緣落點、搖桿快速轉向、落塊快滑與多指按鍵、暫停後放開按鍵、清空資料後不復活進度、各螢幕大小與 VoiceOver 操作。

## 接龍牌桌與街機計時修正

- 貪吃蛇停止的已確認原因：共用計時器每秒更新存檔的 `elapsedSeconds`，原本整份存檔相等的所有權檢查誤判成換局，因而停止畫面計時。現在只排除這個計時欄位，仍比對局次 UUID 與所有其他欄位，保留清除、匯入、換局及真正棋盤變更的防護。相同共用畫面的落塊、打磚塊一併修正，存檔格式不變。
- 五款接龍的抽牌、翻開牌、收牌／暫存格和下方牌列改在同一個 `ZoomBoard`，一起縮放與移動。移除上方獨立橫向捲動區，長按拖曳與點選目的地皆保留。
- 無效拖曳／點選在牌桌下方顯示繁中／英文的對應規則（A 起收牌、K 放空列、紅黑遞減、空暫存格、蜘蛛同花遞減、金字塔合計 13、三峰相差 1）。不跳阻擋對話框，不先移除牌；合法落點框線、單次提交與舊盤面／局次驗證保留。
- 局部驗證：4 項街機存檔回歸測試，涵蓋 60／120Hz 模擬下連續 10 次秒鐘更新及真正 JSON 存讀；6 項既有接龍拖曳規則／原子移動測試；10 項語系／App 資源檢查與 Swift 語法檢查。未執行 Simulator UI 全回歸；iOS SDK 編譯由這批 TestFlight 的必要簽署 Archive 驗證。
- 真機待確認：牌桌上下區的拖曳手感、縮放後落點與提示可讀性，以及貪吃蛇實際持續遊玩、暫停與離開恢復。局部核心測試不代表已實測這些 UIKit 手勢。
