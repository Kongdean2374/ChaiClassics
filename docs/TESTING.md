# 驗證與 iPhone 驗收

CI 真正執行：獨立題庫 Exact Cover／難度／相容性檢查 → `swift test` → Xcode Simulator build → XCUITest。每個命令失敗都使 workflow 失敗；結果包上傳至 Actions artifacts。開發環境已安裝 Linux Swift，可測試 ChaiCore；iOS 編譯、UIKit／SwiftUI 操作與截圖仍必須使用 macOS 的 Xcode Simulator。

0.3.0 的目錄共有 25 款可玩遊戲。核心測試為 223 項，另有 71 項 UI 案例（iPhone 執行時四項 iPad 專用案例應明確 skip），包含八款既有遊戲與新增 17 款的暫停、保存、續玩、勝負、歷史、覆蓋與刪除確認。獨立 iPad 工作另外要求四張實際截圖及 22 條遊戲路徑；結果與尚待完成項目見 [本版驗證記錄](RELEASE_0.3.0.md)。以下三款細項與真機清單仍適用。

日常 TestFlight 依使用者指示採 `validation_mode: beta`：先確認編譯、核心規則與存檔等嚴重問題，介面、手感及完整遊玩由實機測試；收到 bug 後只針對相關案例回歸。main／候選 tag／版本／簽署驗證仍保留，未通過或未執行的 UI 不標成成功。

完整驗收仍可手動選 `full`，依 [來源相依的增量驗證](INCREMENTAL_UI.md) 保留真正通過且未受影響的案例。它與 App Store 門檻不因測試版流程改變；TestFlight 上傳與 Apple 處理也不能取代實機操作、效能與更新保留存檔的驗收。

自動化涵蓋：

- 數獨：150 題／唯一解／ID／三種難度分類（Python）；固定格、答案筆、鉛筆反選、擦除、不清除其他候選、錯誤滿盤不通關、正確滿盤才通關、獨立解鎖、追加 051 不重設進度（Swift）。
- 踩地雷：4 組設定 × 100 個種子；每格八鄰域雷數獨立計算、首點與九宮優先安全、高密度退回首點安全；旗標／揭開互斥、連鎖、勝敗、終局拒絕操作、自訂邊界、序列化恢復。
- 滑塊拼圖：3 種大小 × 3 種難度 × 100 種子＝900 局，每局以反序數 parity 再驗證可解，初局不為完成；另有每種大小 200 步固定種子隨機操作、非相鄰格拒絕移動、完成／終局、重玩及恢復。
- 共用：namespace 隔離、重啟、殘留暫存寫入、主檔損毀備份恢復、版本遷移、未來 schema 拒寫。
- XCUITest：三張卡同排、數獨導覽／模式恢復／無提示按鈕、踩地雷長按插旗與安全揭開／恢復、滑塊盤面恢復。

不要把 Swift Testing 顯示的「0 tests」當成 XCTest 統計；本專案用 XCTest，應看前面的每項測試、Executed 統計與命令 exit code。隨機測試是固定種子，可重現；也不代表穷舉所有局面。

## 發布前使用者必須用真 iPhone 確認

- [ ] 小尺寸／大尺寸 iPhone（如有 iPad 也測）、直橫向、深淺色、較大字級，三欄卡片沒有截斷或重疊。
- [ ] 數獨三種難度可進入；只開放第 001 題；完成後第 002 解鎖，其他難度不受影響。
- [ ] 固定題目不可改，鉛筆可多選／反選，正式答案清掉同格筆記；填錯不標紅、不阻止、不提示。
- [ ] 填滿錯盤仍普通；完全合法盤才顯示完成；暫停／重玩操作正確。
- [ ] 踩地雷三種標準與自訂；首點安全、連鎖、旗標，長按不意外揭開。
- [ ] 困難與 40×40 盤面可拖曳、雙指縮放，觸點落格正確，橫向與旋轉正常。
- [ ] 揭開全部安全格可贏，不必插滿旗；踩雷結束後不能繼續；隨機盤可能需要猜測。
- [ ] 滑塊 3×3／4×4／5×5 與各難度可操作，只移動空格相鄰塊，正確完成與重玩。
- [ ] 三款各走幾步後切換，返回、背景、鎖屏、強制關閉重開，最近已成功寫入的盤面、候選、旗標、雷位、步數、計時均保留且互不影響。
- [ ] 計時只計算可見活躍遊玩，暫停／背景不增加；飛航模式完整可玩。
- [ ] 覆蓋安裝新版保留舊進度，新增 051 不破壞舊題。不要先刪 App，離線存檔不保證卸載保留。
- [ ] 效能、VoiceOver 標籤、長時間遊玩與檔案空間不足錯誤訊息。

以上項目未經真機測試前不得宣稱已驗收或零 Bug。UI 自動化通過不能取代縮放手感與背景恢復真機驗收。
