# ChaiClassics 0.1.3 — 視覺與互動升級

本版將首頁、三款遊戲、暫停／完成畫面及支援設定統一為正式產品介面。沿用原 App、Bundle ID 與簽署流程，TestFlight 與未來正式版本使用相同功能；不增加測試版專用入口、帳號、廣告、內購或分析服務。

## 視覺與畫面

- 首頁仍是三欄遊戲卡片。三款原創向量迷你棋盤取代單一系統符號，搭配真實存檔狀態、柔和分組背景與細框；繁中／英文及大字體可換行。
- 數獨使用靛藍色系、紙本棋盤與工具區。難度卡顯示已完成關卡數；關卡卡片隨可用寬度調整，不顯示答案正誤或解題提示。題目使用一般文字色，玩家輸入與鉛筆維持藍色。
- 踩地雷使用青綠色系、清楚的覆蓋格與經典數字顏色、計時與狀態摘要，保留單點揭開／長按旗標、首點安全、自訂與原生平移縮放。
- 滑塊使用琥珀色系、立體感較清楚的數字方塊與空位，步數及計時一致呈現；保留四方向實際拖曳、原位移限制與點選移動。
- 三款遊戲共用暫停卡、完成摘要與按壓回饋。色彩以深淺模式分別選擇；小型狀態標籤使用主要文字色，不只依靠顏色傳達狀態。
- 通關或遊戲結束後停用暫停入口，避免遮住完成盤面；三款選單使用一致的行內導航標題。深色支援連結沿用具足夠對比的品牌文字色。

## 通關動畫與效能邊界

- 只有遊戲由未完成變成完成才播放；載入已完成存檔、回選單再進入、重複狀態更新不會重播。
- 單一 Canvas 畫 36 片彩帶，以最低 1/30 秒間隔排程，約 2.2 秒後移除整個 TimelineView。沒有常駐粒子、影片、外部圖檔、背景下載或逐格動畫計時器。
- 系統「減少動態效果」、低耗電、非前景狀態會抑制動畫；切換到背景或離開畫面會取消進行中的效果。被抑制的事件不會排隊到稍後重播。
- 裝飾層不攔截觸控，也不加入 VoiceOver 閱讀順序。一般按壓動畫短至 0.14 秒，減少動態效果時不縮放。
- 以上是實作邊界，並非所有真機的 FPS、耗電或效能量測結果；舊型 iPhone／iPad 仍需實機驗收。

## 設定與支援正式化

- 保留一般、遊戲偏好、支援、法律、關於五區，偏好說明精簡為使用效果；關於顯示品牌與實際安裝版本。
- 問題回報使用官方 Email 與支援網站，移除假想 Bug 範例、重複文件標題等不適合正式介面的內容。
- 郵件只開啟可編輯草稿，使用者自行確認寄出；沒有設定郵件服務時，可選取或按鈕複製真實信箱。複製只在使用者點按後執行。
- 繁中／英文隱私政策與使用條款保留離線閱讀及真實官網連結，文件版本沿用 0.1.2，不與每次 App 視覺更新綁定。

## 進度與發布保護

沒有更動三款遊戲核心規則、原有 150 題、完成紀錄、獨立存檔格式／路徑或偏好儲存鍵。新版慶祝狀態只存在記憶體，不寫進遊戲存檔。Debug Simulator 的測試旗標與探針在 Release 排除。

沒有變更 fastlane、match readonly、憑證初始化或 App Store 送審流程。TestFlight 的版本預設更新為 0.1.3，只有手動派送時才使用既有簽署環境。

## 自動驗證與實際範圍

一般 CI 保持快速檢查：核心規則／舊存檔、題目唯一解、雙語與政策資源、Xcode App 編譯、Ruby／YAML 發布安全。新增 CelebrationPolicy 單元測試覆蓋新完成、重複完成、已完成載入及被抑制事件。

獨立「Visual Smoke」是手動、main、免 Apple 憑證的 Simulator 工作流程，僅執行新版本聚焦測試與合成存檔截圖；不增加每次推送或 TestFlight 的全套 UI 前置檢查。它檢查真正滑動後完成、慶祝只觸發一次、重新載入不重播、減少動態效果／低耗電抑制，以及畫面導覽。完整遊戲 UI 測試仍保留，並未移除。

此文件不預先宣稱 CI、視覺測試、簽署或上傳成功。各階段的實際結果以對應 Commit 的 Actions Run 為準；TestFlight 上傳成功後，Apple 的建置處理、外部測試審查與正式 App Store 審核仍是不同階段。

## 真機建議驗收

1. 由既有版本直接更新，三款進度與偏好皆能續用。
2. 檢查三欄首頁、三款棋盤、深淺模式、繁英、大字體與 VoiceOver。
3. 真正完成一局觀察彩帶；離開再開啟已完成存檔不重播。
4. 開啟系統減少動態效果或低耗電後，完成仍正常但不播放彩帶。
5. 驗證地雷大型盤面縮放／拖曳、滑塊四方向移動、數獨輸入／鉛筆／擦除。
6. 檢查官方連結、郵件草稿、沒有預設郵件服務時的信箱選取與複製。
